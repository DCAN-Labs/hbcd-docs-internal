# Access Beta Release Data

## Lasso Pre-Release System

!!! warning "Required pre-release QC"
    HBCD Consortium members must review beta release (BR) data in detail so critical issues can be resolved before the official release.

HBCD Workgroups and SMEs access beta release data through the [Lasso Pre-Release System](https://hbcd-hdcc-qc.lassoinformatics.com/). Data are provided in the same format as official public releases on the [NBDC Data Access Platform](https://nbdc-datashare.lassoinformatics.com/), also hosted by Lasso. SMEs review the data to identify new errors and confirm that known issues and pending updates marked as resolved in the beta release notes have been fully addressed.

## Request Beta Release Data Access

The Lasso Pre-Release System is restricted to HBCD Consortium members and requires a separate account. Access to the NBDC Data Access Platform does not automatically grant access to this internal system, even though both platforms use the same institutional login credentials.

Follow these steps to set up your Lasso Pre-Release System account:

1. Contact your HCAC coordinator, who will:
    - Share and confirm that you have signed the **Data Access Policy** (available to HDCC liaison [here](https://urldefense.com/v3/__https:/hbcdstudy.atlassian.net/wiki/spaces/PC/pages/447479809/Data*Access*Policy*Survey__;Kysr!!Mih3wA!CBflhwBRdkK1LbowcAAxH_XvAZEBWI14So443EvCMvsW78Ubw3uk2U746DWiCg_l41TKK7StVirKzBYHEv8BU_5x2A$)).
    - Complete [this survey](https://urldefense.com/v3/__https:/hbcdstudy.atlassian.net/wiki/spaces/SH/pages/193232971/Airtable*Forms*2024__;Kys!!Mih3wA!CBflhwBRdkK1LbowcAAxH_XvAZEBWI14So443EvCMvsW78Ubw3uk2U746DWiCg_l41TKK7StVirKzBYHEv82-EsXkw$) to submit request for you to access beta release data (Workgroups should be listed in the comment box for WG members). Note that only PIs and Lead RAs/CRCs can complete this survey. <img src="../images/betareleasereview.png" alt="BR" width="90%"/>
1. Navigate to [Lasso Pre-Release System](https://hbcd-hdcc-qc.lassoinformatics.com/), click `Institutional Sign In`, and sign in via your institution credentials.
1. Email Jen Zink at Lasso to provide your username and state that you have completed these steps to gain access to the Lasso Pre-Release System. Jen will follow up with specific onboarding instructions.
