# Access Beta Release Data

## Lasso Pre-Release System

!!! warning "Required pre-release QC of beta release (BR) data"
    HBCD Consortium members must review BR data in detail to resolve critical issues before an official release.

HBCD Workgroups and SMEs access beta release data through the [Lasso Pre-Release System](https://hbcd-hdcc-qc.lassoinformatics.com/). Data are provided in the same format as official public releases on the [NBDC Data Access Platform](https://nbdc-datashare.lassoinformatics.com/), also hosted by Lasso. SMEs review the data to identify new errors and verify that known issues and pending updates marked as resolved in the beta release notes have been fully addressed.
