## BR30.2 Resolved Issues & Updates [C. MADJAR]

### New features

* *Derivatives*:  
    * MRI, EEG and Axtivity derivative concatenation run directly on the de-ID bucket instead of the re-ID bucket  
    * New XCP-D pipeline and hashes  
    * Concatenation of axtivity kinematics outputs  
* *Raw data:*  
    * Removal of frames with line artifact in fieldmaps that pass QC but has a line artifact in one of the frame  
* MAPS tables  
    * Merge total_score and prorated_score fields into a new summary_score field  
    * Exclude total_score and prorated_score  
* `ph_ch_anthro instrument`
    * Inclusion of average_bmi, bmi_for_length_girls_z_score and bmi_for_length_boys_z_score  
    * Blank out z scores if outside of range +/-4  
* Exclusion of setup_004_status from `nt_pa_gabi` instrument (GABI setup)  
* ERICA forms: addition of age and date of administration for reliability forms and derived forms based on the ERICA administration form  
* Normalization starting at 1 instead of 0  
* Remove ecls string in the `ph_cg__medhist` instrument table name  
* Demographics: inclusion of visit missed and visit missed reason to `par_gd_dyn`
* *CDI instrument*  
    * Exclude open text fields  
    * Include `total_produced_percentile_both` and `total_produced_percentile_both_adjusted`
* Exclude incarceration questionnaire  

### Bug fixes

* Fixed the XCP-D concatenated files having only 0 values  
* Demographics:  
    * Domain and Source for static and dynamic data dictionary updated  
    * Fixed the inconsistent use of unknown in the derived ACS variables of the static table  
    * Fixed the no responses showing for the child race multi white in the static table  
    * Excluded non valid sites for recruitment sites in static table  
    * Fixed description of Rolled up cannabis flag in dynamic table  
* Fixed data type and type field for SPM2 score dictionaries  
* Fixed Sequence numbering in `mri_ra_chkl_data` to increment for `start_time` fields

### Known issues

* small_gestational_age empty in `ph_ch_anthro`
* incorrect levels identified for the following instruments  
    * `adm_bm_screen`
    * `mri_ra_chkl_scan`
